# 校园科学工坊：游园会亮灯计划

2026-10-15 当前修订：男女小学生可选角色、保留动物NPC、真实结构器材与长导线。工具台首次进入会解释制作目的，接通参考电路后点击按钮留出两个检测头，不用拖开关进托盘。首次自检成功后可持续使用，不要求每次检测、换场景或刷新后重新自检。详见 `../docs/revision-v4.md`。

2026-10-12 本地课堂版。保存为独立 web-classroom-game，原首页与旧游戏均不修改。无外部依赖，运行 `node server.mjs`，打开 http://127.0.0.1:4182/ 。测试：`npm test`。服务器只监听本机，不供教室其他设备联网使用；正式课堂需实验室部署。

## 范围

四年级下册第4课：校园探索、三个NPC角色类型与巡游成员、工具制作、自由排查三个不同故障、直接拖动器材/探针、修复复验、证据报告、场景交还与庆祝。主角和NPC是透明原创素材，以位移/轻微摆动表现活动，不是完整骨骼或逐帧走路动画。工坊与实验桌使用Canvas绘制。

## 操作

- 点击地面或方向键/WASD移动，靠近按E或点击NPC/工作台；点击物件会先走近再互动。
- 工具台从金色接点拖向另一个接点连线，也可依次点击两个接点。参考电路点亮后，点击按钮取下开关，留出两个检测头，再互碰完成首次自检。撤销可移除最后一条线。
- 实验桌先取下模型电池。已通过首次自检的工具可直接使用，把两个检测头分别拖到同一部分的两个金色接点，自动记录亮灭。不同部位可以自由检测，不要求反复自检。
- 调整连接：点调整灯座连接后，拖动左端（迁移布局中是对应端点）到另一个连接端。更换器材：从上方备用器材拖到对应部件。
- 放回电池复验。调查本分别展示实际修复动作、通电结果、可选引用的检测记录；写一句修复与观察说明即可保存，允许原因暂不确定。返回游园会交还摊主，进入下一例。
- 修复复验成功与原因证据充分分开处理。没有修复前记录或正常部位对照不阻止交还，反馈提醒证据限制；多个调整不能简单归因于某一次。无需恢复故障补记录。报告保存证据状态与反馈，供教师查看，不自动评判自由文本是否正确。

## 数据与限制

浏览器本地保存匿名编号、猜想变化、检测路径、自检、修复、求助和报告。可导出JSON；教师工具可导入多份JSON并导出事件CSV。没有后台、真实实时班级监控、前后测或开放AI聊天。自由文本仅检查最低长度，科学解释需教师评分。不能把测试通过等同教学有效。

## 40分钟课堂实施建议

导入3分钟，观察与猜想5分钟，参考电路及检测器制作6分钟，两个核心病例12分钟，迁移病例8分钟，证据讨论6分钟。总计40分钟，但未经学生试教计时；游戏没有锁定等待或凑时长。当前三个病例在器材层使用同一教学模型，不是三种不同真实电器模拟。

## 本轮检查

Node五项规则测试覆盖不同故障、短路阻止、工具制作、检测安全前提、自由顺序和结案证据。浏览器脚本通过真实DOM/Canvas指针事件检查工具制作、连接病例修复与交还、灯泡病例、导线迁移病例。未做儿童实测，未做学校设备兼容与课堂完成率验证。
