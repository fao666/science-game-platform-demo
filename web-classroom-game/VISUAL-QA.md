# 2.5D课堂试玩版 · 2026-10-12

## 本轮实现

- 保留网页首页版式；课程入口名称与实际新游戏一致，教师入口连接本机真实记录工具。
- 工坊使用原创3D风格精绘背景，工具台、实验桌和出口分别对应真实可点击热点；实验近景采用统一风格桌面素材。属于2.5D贴图与动态Canvas交互，不是实时3D模型。
- 六位固定NPC分布在摊位、工坊门前、作品交流区、长椅与入口边缘；另有一位材料搬运员。使用统一坐标渲染和命中检测，按脚底位置排序前后关系。点击重叠范围时选择最近对象，不按数组顺序误触。
- 保留自由排查、器材拖动、工具自检、安全检测、修复复验与结案证据分级。不用修复前固定证据组合锁住学生。

## 教师查看建议

从首页四年级下册电路进入“游园会亮灯计划”。先与摊位负责人交谈、拿作品，进入工坊制作电路检测器，再自由检测与修复。调查本呈现实际操作、通电结果和可选检测记录；返回摊位后进入下一病例。

三个病例分别涉及连接接触、小灯泡、导线，第三例布局变化。40分钟是课堂组织目标，不能声称所有学生必然玩满40分钟；仍需试教确认实际用时、学习难度及操作可用性。

## 自检标准

1. 场景：入口、工作台与贴图热点对齐；不能用美术覆盖接点和检测反馈。
2. 布局：NPC间距、角色脚底、标牌遮挡、搬运路线；固定居民间距大于180场景像素，搬运员距居民大于120。
3. 交互：鼠标/键盘能进入工坊、两工作台、返回游园会；器材拖动和三个病例仍能修复。
4. 结案：缺少修复前证据可完成，但反馈不夸大原因确定性；未通电复验不能宣称修复。
5. 发布：公开网页无本地文件链接、无登录要求；新游戏资源正确加载；可返回首页。

## 当前边界

不含完整骨骼/逐帧角色动画、实时多人、账号后台、云端数据采集、自动批阅解释。记录存在浏览器本机，可导出JSON/CSV，教师可手工汇总。不要填学生姓名，也不要把导出的研究数据提交到公开GitHub。公开静态预览不代表学校网络一定可访问，需老师实际试开。
