2026年10月26日课堂试玩更新版 · r14

本轮根据导师讨论与试玩反馈，集中改进任务引导、实验操作、角色表现和记录回顾，现可通过浏览器直接试玩。

2026年10月26日实验逻辑与初学者引导修正

  1. 真实灯座连接：取消导线中间独立接头，导线直接接灯座接线柱。接触不良通过拧紧原灯泡处理，桌上可见旋转过程。
  2. 整件检查：自由选择灯泡、整根导线、开关、灯泡与灯座或电池。部件先与模型断开，再进入单独检查区；整根导线只检查两个金属端，无需逐段移动检测器。
  3. 接触点一致：可手动拖动可见金属尖端，也可点“连接检测头”辅助接线。蓝圈标出实际接触位置，接好变绿；明确显示未接触、接触后不通、接触后灯亮。
  4. 增加电池故障：新一轮第三件作品可能因电池无法供电而不亮。采用换入已知正常参考电路的方法检查；不把带电检测头直接接到电池两极。旧版任务的导线故障与记录继续保留。
  5. 亮灭更明显：增强玻璃罩范围内的暖光、白亮灯丝与轻微光粒子，模型增加“已亮起 / 未亮”标识。换小灯泡时仍保留原灯座。
  6. 初学者常驻提示：实验桌下沿增加大字操作区，说明当前在检查什么、为什么这样接、结果意味着什么。可收起、展开，不遮挡操作部件；角色对话与场景反馈字号同步增大。
  7. 保留自由路线：三个任务不分先后，不强制逐项检查或重复自检。报告可先写，复验成功自动完成；重新开始仍先存历史。

2026年10月16日最新更新

  1. 备用器材放回：拿取灯泡或导线后，可拖回原备用按钮，或再点击一次原按钮放回；也可按 Esc。拿取时明确提示，原按钮变蓝并显示“点此放回”。
  2. 快捷键生效范围：Esc 放回仅在实验桌实际拿着备用器材时生效。离开实验桌后清除拿取状态，游园会、制作台和夜间结尾不再出现误提示。
  3. 重新开始入口：按钮移到游戏画面工具栏，与调查本、帮助放在一起。重新开始仍会先保存本轮记录，历史可查看和导出。
  4. 记录保存与复验：可以先写检测判断和修复记录，文字自动保存。通电复验成功后自动更新同一报告，无需重复提交；未点亮时保留记录，不提前算完成。
  5. 检测器下一步引导：参考电路接通后，实验台右侧出现蓝色“下一步：取下开关”大按钮，点击后留下两个检测头，再进行首次自检。

前期整体修改

  1. 补齐运行问题：修复存档异常、部分拖放与交互问题，整理素材引用，并建立 GitHub 版本备份。
  2. 调整学生角色：提供男、女生调查员，缩小夸张头部比例，增加“你”的标识；保留动物同学和校园画风。
  3. 重做任务结构：三位动物分别提出灯塔、纸屋小夜灯和星星舞台的求助。任务不分先后，可以暂存切换，进度分别保存。
  4. 明确角色分工：制作者提出问题，阿圆统一验收作品和报告，猫头鹰老师主持最后的实验回顾。
  5. 加强过程引导：蓝白界面显示总完成数、每项任务状态和下一步去处。工坊出入口可走近进入；移动方式明确为任选一种。
  6. 改进对话：角色对话和操作提示移至画面底部空路面，支持收起和展开，减少遮挡角色。
  7. 调整实验流程：解释制作电路检测器的目的，取消拖开关进托盘等多余动作。首次自检成功后可持续使用，检测顺序自由。
  8. 改进器材与修复：重绘电池盒、导线等素材；灯座连接改为拖动实物夹头。更换灯泡只换玻璃灯泡与螺口，保留灯座和接线。
  9. 修正视觉反馈：灯泡光晕对齐玻璃罩，增加柔和光粒子；移除偏离导线的黄色动画，清理过期检测显示。
  10. 增加前后变化：任务交付前，动物表现为困惑、沮丧或担心；交付后变为感谢和高兴。三件作品交齐后进入全员欣赏亮灯的傍晚场景。
  11. 完善记录与重玩：老师按实际完成顺序展示检测、修复、复验和报告原文。重新开始会先保存本轮记录，历史可查看和导出。

当前试玩范围

使用低压电池模型，包含工具制作、自由排查、修复复验、报告交付和总结。作品亮起与原因证据是否充分分开反馈，不以固定检测顺序作为完成条件。

试玩不要求学生姓名或编号。记录保存在当前浏览器中，不是在线学生管理后台。正式版的名单导入、后台编号与跨设备记录另行设计。

验证与后续反馈

已检查电路规则、六种任务完成顺序、切换续玩、关键拖放、报告与庆祝流程，并对本轮移动说明和保留历史重玩进行专项检查。自动检查与成人试玩不能替代儿童试教。

本次建议重点反馈：学生能否理解下一步要做什么；器材操作是否直观；自由排查是否顺畅；记录与总结是否有助于解释原因。
