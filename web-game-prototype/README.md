# 急诊室复电行动（可玩原型）

这是四年级科学“电路”单元的 Phaser 网页游戏纵向样关，用于验证动态场景、问题解决和过程数据记录，不是最终生产版本。

## 直接试玩

在 `dist` 目录启动任意静态网页服务器，然后访问对应地址。不能直接双击 `dist/index.html`，因为浏览器会阻止模块文件从本地文件协议加载。

## 开发运行

```powershell
npm install
npm run dev
```

## 已实现玩法

- 控制维修机器人在医院内移动；
- 与护士交谈并接收停电任务；
- 探索不同房间并收集电池、灯泡和开关；
- 在配电板上自由连接导线；
- 判断断路、短路和开关状态；
- 闭合回路形成后显示电流流动和医院复电；
- 使用浏览器本地存储记录关键学习行为，并可导出 JSON。

## 数据说明

当前数据仅保存在浏览器 `localStorage` 中，键名为 `hospital-power-prototype-events`。后续接入正式平台时，应改由统一日志接口写入数据库。
