# 第六轮：操作过程与显示一致性

## 学生可以看到的变化
- 实验桌点亮后不再出现偏离弯曲导线的黄色流动点，导线绝缘层保持原色；亮灭由灯泡发光展示。
- 灯泡两端之间不再绘制可能被误认为旁路导线的辅助直线。
- 灯座放大窗口清楚展示按住夹柄、移动夹头、对准后松手的过程；夹头保持抓取位置，不跳到鼠标中心；目标对准变绿。仅打开、关闭、原地点击、未经历移动而松开，不记录修复。
- 夹错可继续调整，取消不计成功；已调整的接头再次打开保留夹紧状态，不伪装成重新修复，不重复记事件。
- 放回模型电池前将两个检测头收回检测器附近，清除旧检测显示，避免看起来仍带着检测工具供电。
- 拨动开关、调整/更换器材后清除已过期的当前检测结果；历史证据保留，首次自检有效状态保留。
- 打开调查本、帮助或灯座窗口时取消悬空器材和未完成拖动，避免关窗后误放。
- 替换导线提示不再固定说右侧，适用于第三件作品的镜像布局。
