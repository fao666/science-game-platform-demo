# 磁铁游戏阅读支持与流程修订

2026年11月2日。用户提醒二年级存在识字差异后补充；此前助手已知年级却未主动提出，属于首次设计的遗漏。

## 查询依据

- 教育部《义务教育语文课程标准（2022年版）》第一学段（一至二年级）：认识常用汉字约1600个，其中约800个会写，并能借助汉语拼音认读汉字。[教育部发布入口](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)。这是一段学习结束时的目标，不是全体二年级学生当前识字量的实测平均数。
- 人教社对早期统编教材的说明：一年级上册会认300字、下册400字，可合计约700字。[人教社教材说明](https://www.pep.com.cn/bks/xxyw/jcjf/201712/t20171211_1921250.shtml)。这是2017年的具体教材安排，不能当成2026年各版本的一致数值。当前学校使用版本、学期进度和个体识字量尚未调查，不能据此判定某个孩子必然不认识哪些字。
- [人教社2025年识字教学讨论材料](https://www.pep.com.cn/bks/xxyw/jzjd/202512/W020251202575246044880.pdf)亦引述2022课标的1600/800学段目标。

## 实现

采用人工核对的91个词条，覆盖器材名、操作词和科学词语，以字上方的拼音显示。动态任务、观察板、提示和结果也会注音；下拉选择使用括号拼音，画布标签单独绘制读音。教师长说明保持原样，学生输入和存储记录不插入注音标记。简化了厚垫板说明和解释输入提示。

检查过词条的字音数量一致、动态注音不嵌套，实际点击预测和测试后仍记录真实操作，材料选择值保持原样；浏览器查看画布、下拉框与注音布局。未对目标班级做识字筛查，也未验证拼音能否解决每个学生的阅读困难。候选生词由设计者筛选，不宣称来自某个精确的年级字表。

## 对框架的修订

项目中的 `science-game-authoring-skill` 已加入设计前的学习者特点检查，要求助手主动提出阅读、表达、操作和前置知识方面的候选障碍及支持，再向教师核实。评估协议新增主动性过程编码，与学生使用效果分开报告。磁铁案例已经参与框架迭代，不再作为未见任务来证明迁移能力。
