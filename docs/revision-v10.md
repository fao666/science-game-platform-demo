# 第十轮：灯泡光效与独立更换

- 光晕与粒子使用原图片玻璃罩的同一组坐标变换，修正原来固定偏移造成的错位。暖光覆盖玻璃内部，少量粒子只在玻璃罩内漂浮，熄灭时一并停止。
- 备用托盘及拖动图像只绘制可拆下的玻璃灯泡和螺口，不携带灯座。使用原素材的运行时裁切保证风格一致，不新增或覆盖原图。
- 替换落点限于玻璃/螺口附近，点灯座底板或接线柱不再误算换灯泡。原灯座与导线位置保持一致；更换提示明确说明只换灯泡，之后仍需放回电池复验。
- 实验桌、工具台和检测器共用同一灯泡绘制函数，光效定位同时生效。

验证：本轮最终46项自动检查通过；针对性浏览器检查备用灯泡拖动、玻璃处放下、通电复验，实际截图核对光效与独立灯泡。没有重复跑全部三任务流程。
