# 二年级《玩磁铁》游戏制作计划与课堂大纲（设计稿）

## 1. 定位与教材依据

- 教材：用户提供的《科学教科版 2年级下册（2026春）》第二单元《玩磁铁》。目录列出第1课《磁铁能吸引什么》（印刷28—30页）、第3课《让小车动起来》（34—36页）、第4课《隔物吸铁》（37页起）。本轮已查看第1课印刷28—30页及第3课34—35页；第4课具体活动、目标与边界须在开发前继续逐页核对。
- **课堂定位建议**：作为上述课题学过后的 40 分钟单元综合探究/应用课。第1课要求先猜测、再用磁铁测试物体并分类；第3课提出不接触小车使其运动。把这些内容合为一节新课会压缩教材原有探究，因此本方案安排真实器材实验与网页游戏结合，由任课教师决定实际教学顺序。
- 暂定名称：**磁力运输队**。学生为校园科学展准备一个“不用手碰小车”的运输演示。情境是学生可制作的模型，避免模拟真实危险运输设备。
- 范围：本轮只形成制作计划和大纲；尚未修改首页、制作游戏或验证 40 分钟时长。正式功能与课堂节奏以教师试教为准。

## 2. 转化桥：教材行动到游戏规则

| 教材活动/问题 | 学生在游戏中的决定与操作 | 系统状态和可见现象 | 学习证据 |
|---|---|---|---|
| 第1课：哪些物体能被磁铁吸引？先猜测后测试、分类 | 从外形不同的日常物体中选取，先放入预测区，再用磁铁逐个试验 | 根据物体内在材料而非颜色或名称决定是否被吸引；结果放入观察板 | 预测、实测、修正与分类理由 |
| 第1课：观察不同形状的磁铁、寻找铁制物品 | 选择条形/蹄形/环形磁铁，在场景中调查材料 | 形状改变外观与握持方式，不凭外形让非铁材料变可吸引 | 选择与测试路径；解释“什么材料”而非只记外观 |
| 第3课：不接触小车使其运动 | 在可移动实验台上尝试手推、磁铁靠近等方法，再调整磁铁位置使装有合适材料的小车前进 | 小车运动方向和是否运动随施力方式、材料及磁铁相对位置改变；展示“没有直接接触”的现象 | 初次方案、调整、结果及解释 |
| 第4课：隔物吸铁（待核原页） | 作为可选延伸：在不同隔板下尝试移动铁质目标 | 结果取决于材料、厚度与距离的简化模型；具体范围经教材和实物测试核定 | 对比条件和解释；不作为首版主目标或强制通关条件 |

磁性规则须由真实器材小试和教师核对。尤其不能把“所有金属都会被吸引”“只要隔着任何东西都能吸引”写进反馈。复合物品应以可见或可说明的实际材料定义，不让学生靠图标猜隐藏答案。游戏不把磁力模拟成精确物理计算器。

## 3. 游戏结构：一条完整任务链

1. **接任务与操作示范**：科学展负责人说明目标：找出可被磁铁吸引的材料，并让模型小车在不直接碰它的情况下到达展台。第一屏展示“去实验台、选物品、先猜再试”，可点击/触控的目标清楚可见；示范只教怎么拿磁铁，不告诉材料答案。
2. **材料调查站**：学生自由选择6—8件材质明确的物品；先预测，再把磁铁移近观察，结果自动记入“我原来想/我看到”。允许改预测和补做测试。至少包含外观相似但材料不同的一对，阻止靠颜色通关。
3. **运输实验台**：在小车装入已查明的可吸引材料，尝试手推和磁铁驱动。学生能改变磁铁位置与移动路径，看到小车轨迹；如果不起动，可检查装载材料或磁铁位置，再试。任务成功需观察到非接触移动，而非点对预设按钮。
4. **应用挑战与解释**：给出稍不同的展台布局，让学生自主选择调查或直接尝试；完成后用图标/短句选择“我改变了什么、看到什么、因此怎样判断”。教师可邀请口头说明。隔物挑战在教材核对后作为可选站，不挤占核心任务。
5. **课堂回顾**：展示预测与实测的差异、两次小车方案和学生解释，供教师投屏讨论；不以尝试次数少或速度快排名。

### 两条合理路线

- **先查材料**：逐一测试，找到合适材料再装车，减少失败次数。
- **先试小车**：先尝试让车动，发现装载不合适后返回材料站验证，再修正方案。

两条路线都应成功，学生根据现象回退和修正；关卡不锁死唯一顺序。

## 4. 40分钟课堂建议

| 时间 | 教师与学生行动 | 游戏承担什么 |
|---|---|---|
| 0—5分钟 | 教师展示科学展任务，学生口头预测什么物品会被吸引 | 情境与任务目标，不直接揭示答案 |
| 5—13分钟 | 小组用真实磁铁测试若干实物，记录一项“猜错了”的例子 | 网页提供对应材料调查站，可在实物前后使用，比较虚实结果 |
| 13—23分钟 | 学生两人合作完成材料站与小车首轮挑战 | 提供可重复、可修正的非接触运动任务和即时现象 |
| 23—31分钟 | 学生修改装车材料或磁铁位置，再完成变化场景 | 记录方案变化和观察结果；教师巡视追问“你根据什么改变？” |
| 31—37分钟 | 教师投屏两类不同路径，讨论“被吸引的材料”和“不碰车也能让车动” | 观察板支持回顾，不自动代写结论 |
| 37—40分钟 | 学生口头或简短出口条说明一次预测、测试和修正 | 游戏保存本轮过程；出口条由教师掌握 |

这是**游戏辅助的一节40分钟课**，不是要求学生连续玩40分钟。网页核心流程的目标是约15—20分钟，留出实物实验和交流。时间为设计假设，须以二年级儿童试教校准。

## 5. 首页接入与产品结构

现有 `web-classroom-game/portal.html` 有一年级到六年级按钮，但目前只固定显示四年级课程卡；点击二年级只提示“建设中”，不会切换卡片。制作阶段应将课程卡改为按年级数据渲染：二年级出现《玩磁铁》卡，显示“二年级下册·第二单元”、主题、预计课堂使用方式和“开始任务”；点击进入独立磁铁游戏入口，游戏内可回二年级课程页。四年级电路卡与入口保持可用。不要用临时链接绕过年级筛选。

磁铁游戏应有独立的状态、存储键、历史记录和导出结构，避免覆盖电路记录。沿用项目最新约定：新游戏/重新开始直接清除未通关本轮；完成后自动归档一次且去重；归档失败不清除已完成轮次；可查看、导出历史。课堂试玩不要求姓名或编号。

## 6. 制作顺序与验收

| 阶段 | 产物 | 验收点 |
|---|---|---|
| A 教材与教师核对 | 第1、3、4课原页摘录、课程目标和器材清单；确认这是综合探究课还是单课辅助 | 教师确认科学边界、真实器材和课堂设备 |
| B 机制样关 | 可玩的“预测—测试—记录—修正”材料站及一辆小车的非接触移动 | 换材料/位置会出现不同结果；错误可恢复；两条路线可通 |
| C 完整课堂版 | 变化场景、观察板、分层帮助、结果回顾、独立存档与导出 | 首次进入知道做什么；提示不泄露材料答案；任务可在目标设备完成 |
| D 首页整合 | 二年级卡片、直达入口、返回路径 | 首页→二年级→磁铁游戏→返回二年级；四年级入口回归检查 |
| E 试教修订 | 儿童操作记录、教师时间记录、修订清单 | 实际检查40分钟节奏、阅读负担、触控命中和科学解释；未试教前不宣称达标 |

## 7. 从电路游戏带来的具体避坑

- **先看真实屏幕，再定美术**：器材外形、可点击区域、拖拽落点和标签一致；检查桌面与小屏，避免“图很好看但孩子不知道点哪里”。
- **目标与操作持续可见**：进入后立即知道任务、地点、第一步；逐层帮助只教操作与证据比较，不提供隐藏答案。
- **场景因果合理**：校园模型实验中用磁铁移动小车，不伪装成真实交通或救援设备。
- **现象和解释分开**：车动了表示任务成功；“为什么动”由学生依据记录说明，系统不替代教师判断。
- **故事不要吞掉实验**：角色对话简短，主要时间留给猜测、测试、调整和讨论；避免把问答套上游戏皮肤。
- **记录不制造门槛**：观察板自动保留真实操作，允许补做；不强迫凑固定证据组合或最少点击。
- **主网页和存档一起规划**：不等游戏完工才补年级入口、返回、重来和历史；四年级数据必须隔离。

## 8. 待教师确认的三个决定

1. 这节40分钟课是《玩磁铁》单元学完后的综合活动，还是只配合第1课《磁铁能吸引什么》？若只配合第1课，小车任务须改为简短课后延伸。
2. 学生使用电脑、平板还是一组一机？课堂是否备有磁铁、铁钉/回形针、非铁材料和小车？
3. 首版是否需要《隔物吸铁》可选站？第4课原页和实物测试核对前，不把它设为必经关。
