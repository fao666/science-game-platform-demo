# 磁力运输队课堂试玩版

2026年11月2日。按教师演示机、学生一人一机设计。入口是主网页二年级卡片，游戏目录为 `web-classroom-game/magnet`。

已实现材料预测、测试与分类，材料和距离影响小车运动的定性模型，两条方向不同的运输路线，可选薄纸板与增大间距实验，分层帮助、真实观察板、解释草稿、教师40分钟课堂安排、本机历史和JSON导出。首次操作可练习，学生可自由切站补测。完成两条运输路线和至少一次材料测试才归档，解释可先口头交流；不将通关等同于学习掌握。

已通过74项项目规则检查并生成静态发布包。浏览器实际走通二年级入口、铁与铜的不同结果、两条路线、填写解释、重复归档去重、重开保留历史；检查1024宽页面和窄屏无横向溢出。规则检查覆盖材料、距离、隔板和历史快照。未经过儿童40分钟试教；教师需用真实磁铁核对模型与器材差异。此版没有实时联网班级管理。

## 素材

使用内置图像生成工具创建三张项目素材，保存于 `web-classroom-game/assets/magnet`。场景为阳光下的校园科学展，人物为薄荷绿和暖黄围裙的两位小研究员，道具采用独立九宫格图集。人物是欢迎插画，未制作人物行走动画。

- `science-fair.png`：宽幅儿童绘本水粉插画，校园科学展庭院、木质实验亭、前景空薄荷绿实验桌、背景模型轨道与展台，柔和青绿珊瑚黄配色，不含文字与人物。
- `explorers.png`：两名7至8岁小学生，全身含鞋，绿围裙女孩抱观察本、黄围裙男孩挥手，儿童水粉插画，透明背景，无文字。
- `props.png`：透明背景、3×3九宫格，各格依次为条形磁铁、蹄形磁铁、环形磁铁、铁回形针、木块、铁片、铜片、塑料积木、带装载槽的四轮木制小车。统一透视、留白、无文字。游戏用CSS/Canvas引用对应格子；铝片与铁片使用相同外观，由材料文字明确区分。

科学边界：小车是简化的材料吸引模型，不模拟磁极、摩擦细节、负载质量与真实磁场。厚垫板表示超出作用距离，不表示材料屏蔽磁力。游戏内明确说明模型边界。钢铁复合车体的具体材料在真实课堂需要教师另行讲解。
