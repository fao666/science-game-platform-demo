# r20 取电池指引与新电池外观 2026-11-02

灯泡未旋到底时增加螺纹外露，完整螺纹金属颈保持与灯座衔接；调整前不显示故障标签，调整后保留已拧紧标识。备用灯泡拖放位置同步。
