# 当前游戏需求与体验约定（2026-10-15 更新）

- 沿用已核对的四年级下册《电路出故障了》与教材中的“电路检测器”概念；本轮不引入新的科学器材名称。原教材定位见既有设计与素材文档。
- 学生在校园游园会中帮助三位制作者：米米的灯塔、慢慢的纸屋、团团的星星舞台。三项任务可按任意顺序完成，也可暂存、切换和继续，各自保存证据、假设、修复、复验和报告。
- 制作者提供情境和求助，不透露实际故障。学生自由检测和排查；一次自检成功的工具可持续使用。修复结果和原因证据强度分别表达，不强迫凑记录。
- 修好的作品及报告统一交给阿圆。交付才计入完成数，并使对应动物从担心状态转为高兴状态。三件全部交付后才进入亮灯庆祝。
- 猫头鹰老师主持回顾，按学生实际完成顺序呈现三件作品的检测记录、修复动作、通电复验、判断和报告原文，支持导出。
- 使用轻快蓝白 UI，展示总进度、当前行动和每个任务的阶段。任务卡可导航；推荐路线不限制选择。角色对话和即时操作提示显示在游戏画面内。
- 结尾为同一校园傍晚的亮灯展示，三个原作品发光，三位制作者、负责人、老师与学生角色同场。可重复进入或返回日间游园会，保留记录。
- 当前仍为本机匿名课堂试玩，不输入学生姓名和编号；不增加服务器或公开学生资料。
- 验收：任意顺序、切换续玩、交付计数、角色前后状态、记录回顾、庆祝门槛、桌面及小屏关键交互。真实课堂效果及儿童完成时间需要试教，不能以自动检查代替。


## 2026-10-29 收尾约定

当前为四任务：前三件自由选序，交齐后由摊主提出第四件欢迎灯求助。每件一处故障，四件全部完成再展示总结。开始新游戏直接进入新轮次，未通关不归档；通关自动归档一次，临时进度可继续。

新手支持：可主动展开的分层帮助，不读取隐藏故障；正常练习接触示意、观察板、可选报告句式；连续失败或长时间无进展仅邀请帮助，不自动弹答案或锁定路线。尚未经过儿童独立试用，不将自动验证等同于无障碍可用或学习效果。
